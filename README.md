## 📊 Project Overview

**Welcome to the E-Commerce SQL Project!** This repository contains a complete end-to-end database structure and analytical query suite built using Microsoft SQL Server (T-SQL). The project is designed to simulate a real-world retail database environment, focusing on clean schema design, structured data loading via bulk imports, and advanced data analysis to drive business insights.

I built this project to analyze a real-world e-commerce dataset from Kaggle and turn messy transactional records into clean, practical business insights. Using SQL, I worked through 20 core questions covering everything from basic sales numbers and shipping delays to advanced customer segmentation and monthly retention. To keep the numbers honest and realistic, I made sure to filter out cancelled and returned orders so the revenue and customer lifetime values reflect actual performance rather than inflated totals.

# Project Objectives

•  Track overall revenue, item sales, and average order values.

•  Analyze payment trends and geographic performance across cities and states.

•  Segment customers using RFM analysis and NTILE scoring to find top VIP spenders.

•  Identify top-performing products, brands, and category return rates.

•  Measure how shipping speed and delivery delays impact customer ratings.

•  Calculate monthly customer retention and month-over-month revenue growth.
